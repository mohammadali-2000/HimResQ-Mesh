# HimResQ Mesh

> **Offline Edge Artificial Intelligence and Peer to Peer Mesh Network for Mountain Disasters and Blackout Triage**  
> *Engineered for Hack in Hills 2026, Manali, Himachal Pradesh*

## Overview

HimResQ Mesh is a zero infrastructure emergency response coordination platform designed specifically for high altitude disaster zones. During cloudbursts, landslides, and severe mountain weather, telecommunication towers and electrical grids fail completely. 

HimResQ Mesh transforms consumer smartphones and low cost packet radios into an intelligent off grid emergency network.

## Key Capabilities

1. **Peer to Peer Mesh Relay:** Uses Bluetooth Low Energy and Long Range LoRa packet radio frequencies to hop emergency SOS signals across adjacent devices without cellular towers or internet connectivity.
2. **On Device Artificial Intelligence Triage:** Executes quantized small language models locally on consumer devices to categorize injury severity, guide first aid, and format vital signs into ultra light binary packets.
3. **Offline Topographical Mapping:** Plots casualties, evacuation corridors, and safe zones on local vector maps with zero cloud dependency.

## Architecture

```
[Stranded User / Sensor]
           │
  (Bluetooth Low Energy / LoRa)
           ▼
[Peer to Peer Mobile Mesh Node]
           │
  (Local Compressed Packet)
           ▼
[On Device AI (llama.cpp / ONNX)]
           │
  (Triage Classification)
           ▼
[Offline Map Tactical View (Leaflet / MapLibre)]
           │
           ▼
[Rescue Command Evacuation Dashboard]
```
